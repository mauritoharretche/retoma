# RETOMA project instructions

## Product and privacy boundaries

- RETOMA is a single-user personal activity management application.
- Users manage only their own activities and progress.
- Data remains local to the device.
- Do not add user accounts, multi-user functionality, social features, cloud synchronization, external tracking, advertising, or analytics.
- Do not collect other people's personal information.
- Do not add AI model training, evaluation, inference, or serving features.
- Do not add regulated-data processing.
- Never commit credentials, secrets, API keys, tokens, private information, or real user data. Use synthetic test and demo data only.

## Engineering practices

- Keep business logic independent of React wherever practical.
- Use strict TypeScript.
- Write tests for business rules and important user flows.
- Run tests, lint, and build before considering a task complete.
- Keep documentation updated.
- Make small, meaningful changes.
- Never create commits without explicit confirmation from the project owner.
